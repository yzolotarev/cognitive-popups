# IDEAL STATE — cognitive-popups 1.0 «можно не трогать полгода»

Принцип: **меньше, честнее, надёжнее.** ИИ даёт сырьё (слова, цитаты, место расхождения). Человек группирует, связывает, объясняет «почему» — на бумаге и в своих гипотезах.

## 1. Надёжность (ни одного тупика)
- [ ] Повторное нажатие любой клавиши поднимает живое окно; мёртвое (процесс умер / окно закрыто компоситором) снимается сразу.
- [ ] Каждый шаг закрывается: «готово», «отмена», таймер или выход. Esc в окне шага = отмена.
- [ ] Тесты никогда не трогают боевое состояние (изоляция всегда, и в pytest, и в run-tests.py).
- [ ] Схема БД никогда не понижается; хранятся только 3 последних бэкапа.
- [ ] Сервис стартует без моста (`Wants=`); всё офлайн работает; `var/` в `.gitignore`.
- [ ] Повторный Alt+W по тому же тексту не плодит дубль и новое окно.

## 2. Честная обратная связь (сердце продукта)
- [ ] Догадка сверяется **только с текстом**: короткое выделение или эхо прошлых узлов → опора = последний абзац.
- [ ] `mismatch` снова хранит фразу-расхождение; узлы — в `nodes_json`; старые строки перенесены.
- [ ] Ворота в коде поверх модели: вопрос → «это вопрос: какой твой ответ?»; размытые маркеры без конкретики → «размыто».
- [ ] Отметка и одна строка «что у тебя верно» остаются на экране до закрытия, не мигают.
- [ ] Узлы не притворяются кликабельными словами.
- [ ] Возвраты: промах возвращается через 2 → 5 → 12 → 30 дней без показа текста; «подтверждено позже» только в другой день.

## 3. ИИ не думает за человека
- [ ] Alt+C: «что держится + где смотреть (цитата)», без решения упражнений.
- [ ] Проверка гипотезы без «дай недостающий кусок».
- [ ] «Абзац из твоих гипотез» — только по явной просьбе и без неверных догадок.
- [ ] Слова-подсказки — содержательные, не ярлыки категорий; одна плохая карточка не роняет все 4.
- [ ] Устаревший override промпта распознаётся и не глушит новый промпт молча.
- [ ] Самопроверка Сунга в конце шага: 4 вопроса (упрощал? группировал? связывал с картиной? вспоминал?), 1 клик, без оценок.

## 4. Удобство и визуал
- [ ] 6 основных клавиш (Alt+W, Ctrl+Alt+P, Alt+E, Alt+C, Alt+I, Alt+K) в репо-конфиге; Ctrl+Q убран; справка Alt+K верна и сверяется тестом с конфигом.
- [ ] Ошибки — одной человеческой строкой; деталь в лог.
- [ ] Модель недоступна → черновик слов без ИИ (`instant_cues`) с пометкой.
- [ ] Один источник цвета/шрифта (`theme.py`), контраст текста ≥ 4.5:1, одна функция reduced motion для всех анимаций.
- [ ] По умолчанию выключены: HUD, таймер Universe, звук песка.
- [ ] **Обзор** (Alt+K → «Обзор», `cog stats`): твои промахи дословно, повторяющиеся спотыкания, что вернётся, где подвела система. Без процентов, серий, минут.
- [ ] **Катсцена «на бумагу»**: после 4 слов слова разлетаются по углам — ход переходит к руке. ≤ 1 с, чистая функция кадра с тестом, мгновенно при reduced motion.
- [ ] **Карточка сессии**: созвездие из гипотез сессии (промахи — яркие), SVG, детерминирована, сохраняется в «небо».

## 5. Полгода без обновлений
- [ ] Один конфиг модели (`COGNITIVE_API_URL`, `COGNITIVE_MODEL`, `COGNITIVE_API_KEY`) для всех вызовов; 4xx → понятное «модель не найдена — поменяй …».
- [ ] `cog doctor`: Python/GTK, буфер обмена, сервис, бинды, модель, флаги, целостность SQLite.
- [ ] `cog maintain` (еженедельный таймер): ретенция телеметрии, бэкапов и событий; заметки, гипотезы и журнал не удаляются никогда.
- [ ] Один каталог состояния для сервиса, скриптов и CLI.
- [ ] Совместимость с будущим PyGObject (обёртки устаревших API), битый `focus.json`/`history.json` не валит демон.
- [ ] Мелкие баги ядра: newest-first подготовка, простой по стенным часам, честное время закрытия упавших сессий, `\n` в промпте, отрицание в проверке попытки, «отравленная» пачка Universe.

## Не делаем
Флешкарты, ИИ-группировка, серии дней, проценты «правильно», новые окна сверх перечисленного, новые pip-зависимости.

## Критерий готовности
Все пункты отмечены, тесты зелёные (pytest и run-tests.py), `cog doctor` чист на свежей установке, README описывает ровно то, что есть.
