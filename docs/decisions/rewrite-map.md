# Карта переноса: старое поведение → сценарий v1 → приёмка

Требование PR-02 запрещает переносить старую архитектуру 1:1: для каждого
переносимого поведения нужен новый сценарий и проверяемая приёмка. Ниже —
фактическое состояние, а не план. Строки, которые не переносятся, перечислены
явно с причиной.

Вход: [`legacy-inventory.md`](../requirements/legacy-inventory.md).

## Перенесено

| Старое поведение | Новый сценарий v1 | Где | Чем проверяется |
|---|---|---|---|
| Четыре опоры из выделения с раскрытием | Alt+W: четыре смысловые опоры × три слоя (бытовая опора → точный термин → роль в источнике) | `four-words`, `FourWordsWindow`, `services::mechanism` | `requires_four_complete_layers_not_a_four_word_summary`; окно с реальным выделением (desktop evidence) |
| Объяснение / вопрос по фрагменту | Alt+E: комментарий к видимому фрагменту, ответ модели отдельным полем | `comment`, `note`, `NoteWindow` | `provider_configuration_failure_preserves_input_before_any_networking` |
| Пример и «ступенька» | Внутри Alt+T: одно упражнение по фрагменту, критерий фиксируется до ответа | `task`, `ThinkingWindow` | `thinking` flow; desktop: окно с захваченным текстом |
| Микропробы и задачи | Alt+T: задание → собственная попытка → feedback | `task` | попытка сохраняется дословно до сравнения |
| Проверка ответа | Точная код-проверка в «Проверка», не семантическая оценка | `assessment`, вкладка «Проверка» | `composite_updates_only_independently_checked_components…`, `help_unknown…` |
| Гипотеза до сверки | Ctrl+Alt+P: собственный прогноз фиксируется до ответа модели | `prediction` | порядок событий в потоке `thinking` |
| Заметки и объяснения своими словами | Заметка хранится дословно, интерпретация ИИ — отдельное поле/автор | `note`, journal | `reader_authorship_survives_a_round_trip_verbatim` |
| Alt+S: предмет, цель, контекст, проценты | Экран «Предметы»: предмет, долгосрочная цель, контекст, ручные веса | `hub`, `Subject` | `manual_weights_reject_unknown_names…`, `gui_subject_rejects_unknown_mechanism_weights…` |
| Alt+I: цель, шаг, план под часами, продолжение | «Занятие»: черновик/свой план, версии, пауза, восстановление | `hub`, `learning` | `gui_session_and_draft_recover_without_completion_or_reviews`, `restart_preserves_plan` |
| Learning V2: единицы, свидетельства, самооценки | «Память» и «Проверка»: единицы без карточки, самооценка отдельно, FSRS только по проверенному | `learning`, `assessment` | `snooze_preserves_memory`, `scheduler_failure_rolls_back_every_component_and_attempt` |
| Director / Auto popup как основа предложений | Opt-in MRT: verified-error, 50/50, частотные лимиты, `missing` | `experiment`, вкладка «Опыт» | `experiment` tests; `docs/decisions/mrt-protocol-v1.md` |
| Возврат к сохранённому материалу | Повторное открытие заметки/сессии из хаба; содержимое не подменяется | `hub` | `gui_session_…` (восстановление после перезапуска) |

## Не перенесено (осознанно)

| Старое поведение | Причина | Что вместо |
|---|---|---|
| Recall Popup (Alt+V) | В контракте ровно пять действий; шестое действие не добавляется | Проверка памяти живёт во вкладке «Проверка» |
| Resume / Alt+B | Отдельное действие вне пяти; возврат делается открытием записи | Открытие из «Истории»/«Занятия» |
| Daily Intentions | Дублирует Alt+I | Цель и план в «Занятии» |
| Universe / граф связей мыслей | Кандидат (OD-03), не принято | Личные записи без графа |
| Orbital / Sand / звуки | Реализация переосмысляется (Q03) | Slint-интерфейс, без тем и звука |
| HUD / Focus / Alt+R | Заморожено, вне v1 | — |
| Episodic Recorder (экран/аудио) | Принято Q09: не нужно для штатного обучения | Ничего не записывается фоном |
| Popup Reels | Кандидат (OD-12), функция не определена | — |
| Lightbulb / Opportunity / Micro-Clarification | Три движка консолидированы в один MRT-механизм | MRT-предложение в рамках согласия |

## Границы

- Перенос — это поведение и гарантии авторства, а не структура модулей: старые
  GTK/Python-компоненты в v1 не воспроизводятся.
- Строки, требующие реального desktop (hotkey, выбор в браузере/PDF, фокус) или
  Windows, не считаются принятыми по этой карте: см.
  [`desktop-evidence-2026-10-27.md`](../quality/desktop-evidence-2026-10-27.md).
