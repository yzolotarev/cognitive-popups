# Инвентаризация наследия: вход в OD-08

Составлено по фактическим источникам: истории этого репозитория (снимок `39e717e`,
удалённый из `main`, но доступный в Git) и рабочему чекауту v1, который содержит
Learning V2 и более поздние ветви. Наличие кода ниже означает «поведение
существовало», а не «его нужно перенести».

Статус каждого направления — **ПРЕДЛОЖЕНО**, не решение автора. Итог фиксируется
в OD-08 и в реестре требований.

## Что важно не потерять при переносе

1. **Авторство.** Собственный текст и гипотеза сохраняются дословно до ответа модели.
2. **Порядок.** Гипотеза → сверка; попытка → решение; критерий → ответ.
3. **Отказ.** Невалидный ответ модели, отсутствие ключа и старый clipboard не должны
   превращаться в ложный успех или терять запись.
4. **Отсутствие навязанной очереди.** Практика и проверки — по действию или
   согласованному напоминанию, не по таймеру.
5. **Локальные данные.** История v1 не мигрирует автоматически; архив read-only.
