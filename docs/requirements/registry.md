# Реестр требований v1

Единственный источник трассировки для полной версии. Спецификация-основание:
[`docs/spec/cognitive_exoskeleton_v0_2_full_spec.md`](../spec/cognitive_exoskeleton_v0_2_full_spec.md).

## Правила

- ID и статусы перенесены из спецификации без изменений. Менять ID нельзя.
- `Состояние`: `не начато` · `в работе` · `ждёт решения` · `реализовано` · `принято на desktop` · `отклонено автором`.
- `Реализация` и `Доказательство` заполняются ссылками на код/PR, автоматические тесты и desktop-протоколы. Строка не закрывается мок-тестом, если спецификация требует реального desktop.
- Строка с `ПРЕДВАРИТЕЛЬНО` / `ОТКРЫТО` / `КАНДИДАТ` / `ИСТОРИЧЕСКОЕ` не становится обязательной молча. Её блокирующее решение фиксируется в [`docs/decisions/open-decisions.md`](../decisions/open-decisions.md).
- При расхождении статуса с текстом спецификации действует более осторожный статус.
- Этот файл проверяется тестом `tests/traceability.rs`: отсутствие ID или смена статуса без спецификации валит CI.
