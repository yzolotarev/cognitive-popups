# P1: платформенные пробы и поддерживаемые окружения

Документ фиксирует **предложение** для OD-10 и порядок проб. Итоговый список
поддерживаемых окружений появляется только после протоколов с версиями и
результатами; CI-раннеры не считаются пользовательским desktop.

## Предлагаемые целевые окружения

| Окружение | Статус | Почему |
|---|---|---|
| Windows 11 x64 23H2+ | поддерживается | Актуальная поддержка, WebView2/подпись/установщик доступны |
| Windows 10 22H2 x64 | best-effort | Достижимо, но без обещания полного паритета |
| Ubuntu 24.04 LTS, GNOME, Wayland | поддерживается (после проб) | Массовый десктоп; проверяются порталы и фокус |
| Ubuntu 24.04 LTS, GNOME, X11 | поддерживаемый fallback | Полный контроль хоткеев/выделения через X11 |
| KDE Plasma 6, Wayland | поддерживается (после проб) | Лучшая поддержка GlobalShortcuts-портала |
| Arch/Hyprland и другие композиторы | best-effort | Среда автора, но без универсальных гарантий |
| macOS | вне v1 | Не входит в согласованные платформы |

Правило: «поддерживается» означает, что сценарии E2E-01…12 пройдены на этом
окружении и ограничения опубликованы. Остальное — best-effort без обещаний.

## Ожидаемые ограничения (проверить, не предполагать)

| Область | Wayland | X11 | Windows |
|---|---|---|---|
| Глобальный хоткей | Портала GlobalShortcuts нет во всех композиторах; вероятен путь «команда, назначенная пользователем в своём окружении» | `XGrabKey` предсказуем, возможны конфликты | `RegisterHotKey`, конфликты и elevation-окна |
| Чтение выделения | Часто доступно через primary selection (`wl-paste`), но не гарантировано приложением | primary/clipboard читаются напрямую | Только clipboard после синтетического Ctrl+C или UI Automation |
| Синтетическое копирование | Может требовать RemoteDesktop-портал или `uinput` с правами | XTEST | `SendInput` + ожидание изменения clipboard sequence |
| Фокус и прозрачность | Зависит от композитора и протокола; оверлеи могут не получать фокус | Предсказуемо | Прозрачность и topmost настраиваются, есть ограничения DWM |
| Возврат к материалу | Зависит от приложения и URL/файла | Обычно достижимо | Обычно достижимо через ShellExecute/UI Automation |

Ни одна строка таблицы не является обещанием: каждая либо подтверждается протоколом,
либо попадает в список ограничений.

## Пробы P1

Каждая проба — отдельный протокол с версиями, шагами, результатом и fallback.
Одноразовый код проб не переносится в продукт.

- **S1. Хоткей.** Регистрация Alt+W/Alt+I/Alt+S/Alt+T; повторная регистрация; конфликт;
  поведение при отсутствии прав; срабатывание при фокусе в целевом приложении.
- **S2. Выделение.** Firefox, Chromium, LibreOffice Writer, Okular/Evince, VS Code,
  терминал. Пустое выделение, multiline, Unicode, большое выделение.
- **S3. Clipboard.** Изменение sequence/тайм-аут, старое содержимое, отсутствие доступа,
  копирование из защищённого приложения.
- **S4. Окно и фокус.** Пассивный показ не крадёт фокус; ввод получает фокус предсказуемо;
  закрытие возвращает исходное приложение; окно не попадает в alt-tab, где это возможно;
  позиционирование у курсора/выделения на нескольких мониторах и при scaling.
- **S5. GUI-кандидаты.** Tauri v2 и Slint на сценариях S1–S4: прозрачность, IME/кириллица,
  ввод, память, холодный старт, размер пакета, установка.
- **S6. Установка/автозапуск.** Пользовательская установка без прав администратора;
  автозапуск с явным управлением; удаление без потери данных.
- **S7. Wayland-ограничения.** Проверить GlobalShortcuts-портал на GNOME и KDE; вариант
  «пользователь назначает команду»; RemoteDesktop-портал для синтетического копирования;
  поведение при отказе в разрешении.
- **S8. Windows-ограничения.** RegisterHotKey при elevation, clipboard после SendInput,
  многооконность, DPI, SmartScreen при неподписанной сборке.

## Критерии прохождения пробы

1. Повторяемый шаг-лист, выполненный на зафиксированной версии ОС/desktop/приложения.
2. Для каждого отказа — наблюдаемое поведение и согласованный fallback.
3. Нет скрытого обхода разрешений; отказ пользователя не ломает штатные сценарии.
4. Ограничение попадает в публикуемый список ограничений, а не замалчивается.

## Шаблон протокола

```text
Проба: Sx
Гипотеза:
Окружение: ОС/сборка, desktop/compositor, приложение/версия, commit
Шаги:
Наблюдения:
Результат: подтверждено / ограничено / невозможно
Fallback:
Ограничение для документации:
```

## Что CI не закрывает

CI проверяет сборку, тесты и артефакты. Он не проверяет глобальные хоткеи, чтение
выделения, фокус, прозрачность, порталы Wayland, права Windows, установку и
автозапуск. Эти строки закрываются только протоколами S1–S8 на реальном desktop.
