# План разработки на ПК владельца

Порядок — по B10: сначала отдельные системы с CLI и тестами, окна последними. Каждый этап закрывается, когда выполнены его критерии готовности. v1 на Python продолжает работать как ежедневный инструмент, пока новая версия не догонит его по пяти главным окнам.

Репозиторий: `yzolotarev/cognitive-popups` (Rust). Пакет документов — `docs/v2/`. Где он расходится со спецификацией v0.2 (`docs/spec/`), действует пакет (сверка — `docs/v2/reconcile-rust-spec.md`).

## P0. Проба стека — 1–2 дня. Решает судьбу Rust (B35)

**Пройдено 29.10 (B45):** median 4,5 мс, ввод, Esc, typst; окно по горячей клавише — `OnDemand`.

Маленькая программа `spikes/gtk4-probe` на Rust + GTK 4 + `gtk4-layer-shell`, на Hyprland.

**Критерии.** Все должны выполняться; если хоть один не выполнен — откат на Python v1 (прежнее B2):
1. Окно появляется у курсора **без захвата клавиатуры** (`KeyboardMode::None`), а по клику переключается в режим ввода (`OnDemand`).
2. Время от сигнала до видимого окна при заранее созданном окне — замерить; цель < 100 мс (результат записать как baseline OD-13).
3. Русский ввод и вставка в поле работают.
4. Формула `P(A∣B) = P(A∩B) / P(B)` рисуется локально (typst или другой рендер); если рендер не найден — текст, и это записано как риск.
5. Esc закрывает окно; два окна одновременно — второе поднимает первое.

## P9. Выпуск

Бета-тестеров нет: продукт должен ставиться и объяснять себя сам.
- Пакет: AUR (`cognitive-popups-git`) и бинарники в GitHub Releases; промпты ставятся в `~/.local/share/cognitive-popups/prompts`.
- `cognitive-popups doctor`: GTK, layer-shell, Hyprland, wl-clipboard, трей, связка ключей, ключ ИИ — что есть, чего нет и как поставить.
- Первый запуск: блок для `hyprland.conf` (классический и Lua), хаб на вкладке «ИИ».
- CI «чистая установка»: контейнер Arch, установка пакета, `doctor`, скриншоты.
- **Готово, когда:** человек без контекста ставит по README, проходит сквозной день и не задаёт вопросов.
