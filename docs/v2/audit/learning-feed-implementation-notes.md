# Learning feed — implementation notes, 31.10.2026

Утверждённый план: последняя редакция в переписке; решение B96. Ветка `feat/learning-feed`. Это обновление исходников, не установка работающего приложения.

## Реализовано

- Новый доменный контракт `learning-v1`: задания-вопросы и действия без проверки, отношения между заданиями вместо универсальных уровней, экспериментальная политика по умению без вывода об освоении.
- Содержательная генерация и отдельная проверка всей цепочки: сборка исходного ответа, покрытие компонентов существующими шагами, исправление отказа максимум дважды.
- Эпизоды помощи, вложение, возвращение родителя и исходного вопроса, запрет оценивать action, AfterHelp после любых подготовительных шагов. Ни одна из этих записей не вызывает Memory::review.
- SQLite: версия кэша в ключе контекста, ревизии, идемпотентные события, черновики, исходные/завершённые эпизоды и явное происхождение. История вопросов повторения и модельный фильтр вариативности, без изменения фиксированных блоковых вопросов.
- GTK: новая «Лента», три самооценки, необязательный письменный ответ, помощь внутри ленты, отдельная просьба построить карту, плавные переходы, клавиатура, жест на свободном элементе управления. Старые операции доступны по ссылке.
- Необязательная обратная связь при явной остановке и согласии на эксперименты; отдельно от учебных исходов. Нет максимизируемой метрики удержания.
- CLI `practice learning`: state/generate/support/reveal/grade/skip/return, --db, --text, --key, --answer; `--goal` задаёт область контекста. CLI диагностический: JSON содержит скрытые опоры.

## Консервативные уточнения

- Жест навигации привязан к нижней области управления, чтобы не забирать выделение текста, ввод и прокрутку. Кнопка и клавиатура остаются основными путями desktop.
- При достижении предела помощи предлагается имеющаяся опора как объяснение и возврат. При провале содержательной генерации — явный повтор; непроверенный разобранный пример не подставляется.
- Проверяемые кодом семейства FSRS сохраняют процедурную проверку; новые числа не называются переносом. Первые фиксированные экспериментальные вопросы B81 не регенерируются.
- Ежедневный предел обратной связи считается в UTC; это записано в B96. Сама анкета не всплывает автоматически.
- Sway для изолированных снимков распакован с зависимостями в /tmp, без установки системных пакетов. Screenshot runner явно использует промпты рабочей копии, а не установленную старую версию.

## Пределы подтверждения

Тесты и fixture-снимки подтверждают программные переходы, а не эффективность педагогики. Самооценка после раскрытия может быть узнаванием. Ответ на исходный вопрос сразу после помощи не является независимым удержанием. Нужны последующие новые задачи и пользовательский прогон: посильность, раздражение, однообразие, желание продолжить; длительность и число переходов не являются целью оптимизации.
