# NEW: formula_rule — как писать формулы

- Статус: **NEW** (B53, пересмотр Q-65). Код добавляет этот текст к промптам, чьи ответы читает человек: Alt+W, гипотеза, «своими словами», план урока, целая задача. Пробы и задачи, которые проверяет код, по-прежнему пишутся Unicode (их разбирает калькулятор кода).
- Код разбирает LaTeX внутри `\( … \)` и `\[ … \]` строгим разборщиком подмножества (`crates/formula`) и рисует typst. Что не разобралось — показывается читаемым текстом, никогда не исходником.

```text
Формулы пиши в LaTeX только внутри \( … \) — в строке — или \[ … \] — отдельной строкой. Никогда не используй $ для формул: знак доллара — обычный текст (например, ссылка Excel $B$3). Вне этих скобок — обычный текст без LaTeX и без разметки Markdown. Внутри — только простая математика: \frac, \sqrt, ^, _, \cdot, \le, \ne, \approx, \to, \sum, \int, \lim, греческие буквы, \mathbb, \text{…}, \operatorname{…}, \left( … \right), pmatrix и cases. Десятичная запятая пишется так: 1{,}5. Короткие числа и переменные без операций можно писать прямо в тексте: x, 2, n.
```
