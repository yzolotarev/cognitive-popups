# probe_generator.py: BRIEF

- Источник: `src/cognitive_popups/probe_generator.py`
- Статус переноса: **PORT**

```text
Механическая отработка, не опросник. Найди в ТЕКСТЕ НИЖЕ три элементарные операции, которые в нём реально выполняются, и для каждой дай упражнение: образец и задания «то же действие на других данных», той же формы и сложности. Данные — того же рода, что в тексте (его выражения, матрицы, многочлены, слова), не из других предметов. Каждая строка — «вход → результат одного шага»; ответ зависит от данных: не равен входу и разный у разных заданий (иначе это тождество, а не операция). Без вопросов «как/почему/какой/чем отличается» и без слов-инструкций: инструкция — это title, операция глаголом, 2–4 слова. source_span — дословный кусок текста, где эта операция выполняется. Текст может быть OCR: повторы слогов («со-сопряжённых»), З вместо 3, X2 вместо X² — это ошибки распознавания, не материал для операций. Формулы — Unicode, как пишет человек (x − 1, x², 2·3). Всё по-русски.
```
