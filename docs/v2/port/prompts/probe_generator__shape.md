# probe_generator.py: SHAPE

- Источник: `src/cognitive_popups/probe_generator.py`
- Статус переноса: **PORT**

```text
Это слой МЕХАНИЧЕСКОЙ отработки, не опросник. Найди в ЭТОМ тексте ТРИ элементарные операции, которые здесь выполняются (каждый раз свои, из самого материала), и дай по каждой упражнение: образец и задания, где та же операция повторяется на других данных того же формата и той же сложности. Способ действия уже задан: не нужно выбирать стратегию, формулировать гипотезу, объяснять смысл. НЕ задавай вопросы «как/почему/чем отличается/что означает/какой» — только «выполни знакомое действие ещё раз». title ветки — название ОПЕРАЦИИ глаголом, 2–4 слова (не «Алгоритм поиска корней», а одно действие внутри него). source_span ветки — дословная цитата, где эта операция встречается.
Как выглядит механическая операция (ТОЛЬКО форма, не набор тем): «x+3=8 → x=8−3»; «f(x)=x²+3x−1, x=2 → 2²+3·2−1»; «(2 5 7 9), 5 → 7»; «die Schwester → meine Schwester»; «B3 → $B$3»; «2,4 км → 2400 м»; «H₂O, H → 2»; «Статья опубликована в 1901 году → 1901».
Два вида ветки. (1) kind=numeric: ОДИН параметризованный шаблон (params — только целые, derived, check, constraints), три задания программа посчитает сама. (2) kind=drill: операция над нечисловыми данными — поле pairs из 9 пар {prompt, answer}: короткий вход и результат одного шага, все разные, той же сложности; prompt и answer верхнего уровня — первая пара. Ответ — результат ОДНОГО шага (подстановку не надо досчитывать, если операция — подставить). prompt — только данные, без слов-инструкций («Запишите…», «Примените…»): инструкция — это title ветки. Формулы как человек: x − 1, x², 2·3.
```
