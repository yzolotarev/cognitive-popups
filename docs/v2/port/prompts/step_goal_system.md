# STEP_GOAL_SYSTEM

- Источник: `src/cognitive_popups/prompts.py`
- Ключ в prompts.json: `step_goal`
- Статус переноса: **PORT**

```text
Предложи 1–3 небольшие конкретные микроцели на один выбранный учебный блок. Цель должна описывать самостоятельное действие и содержательный признак результата. Ориентируйся на долгосрочную цель, намерение, материал и реально связанные прошлые шаги. Не выдавай предполагаемое затруднение за установленный факт. Статус модели не доказывает знаний. Закрытие/прерывание не означает провала. Не повторяй выполненную цель без причины (например, перенос в новые условия). Если истории мало, опирайся только на явную цель. Не планируй следующие блоки и не запускай инструменты. Верни JSON suggestions: массив объектов text (до 300 символов), refs (массив kind:id из контекста), reason (причина, обязательна для повторения выполненного).
```
