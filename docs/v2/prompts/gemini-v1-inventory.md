# Промпт для Gemini: полная инвентаризация функций Cognitive Popups v1

**Как использовать:**
1. Приложи к Gemini файл **`v1-code-for-gemini.md`** (3,4 МБ): весь код `src/`, `scripts/`, `config/`, `рефлексия/` и `PROJECT_MAP.md`.
2. Если Gemini примет ещё один файл — приложи **`v1-docs-for-gemini.md`** (1,5 МБ): спецификации и отчёты v1. Он необязателен.
3. Вставь текст ниже как сообщение.
4. Ответ Gemini сохрани файлом и передай Claude.

Если Gemini пишет, что файл слишком большой, — сначала только код, без документации.
---

Ты получаешь полный исходный код программы Cognitive Popups v1 (Python, GTK3, Hyprland). Твоя задача — **полная инвентаризация всех функций программы**: пользовательских и служебных. Ничего не проектируй и не оценивай, только опиши, что есть в коде.

## Что считать функцией

Любое поведение, которое можно отдельно включить, вызвать или наблюдать:
- окна и клавиши (Hyprland-привязки, сигналы демона, пункты меню);
- кнопки внутри окон, которые запускают отдельное действие;
- фоновые механизмы, таймеры, автоматические окна и эксперименты (режимы off / shadow / experiment / active);
- генерации через модель (каждый промпт — отдельная функция);
- проверки ответов (кодом / моделью / самооценкой);
- хранилища, таблицы SQLite, миграции, файлы состояния;
- настройки: переменные окружения, файлы в каталоге состояния, JSON-конфиги;
- CLI-скрипты (`scripts/*`) и их подкоманды;
- модули, которые написаны, но нигде не вызываются (пометь как «не подключено»).

## Формат ответа

### 1. Таблица (Markdown)
Одна строка на функцию, столбцы:

`№ | Название | Как вызывается (клавиша / сигнал / кнопка / таймер / CLI / внутренний вызов) | Файлы и функции (path:function) | Что видит пользователь (дословные тексты окон и кнопок, если есть) | Что сохраняет (таблица / файл) | Статус (live / frozen / experiment / shadow / off-by-default / not wired) | Есть в карте Claude? (ID или «НЕТ»)`

### 2. Список «НЕТ»
Отдельно — все функции, которых нет в карте Claude (список ниже). Для каждой — 2–4 предложения: что делает, откуда вызывается, какие данные пишет.

### 3. Расхождения
Где описание Claude (по названию ниже) противоречит коду. Кратко: ID, что в коде на самом деле, файл:строка.

### 4. Служебное
- все таблицы SQLite с полями (по миграциям `records.py`, `notes.py`, `event_log.py`, `universe.py`, `episodic/store.py`);
- все переменные окружения `COGNITIVE_*`;
- все файлы в каталоге состояния (`*.json`, `*.enabled`, `*.off`, `*.lock`);
- все промпты: ключ, файл, назначение;
- все Hyprland-привязки из `config/*.lua`.

## Правила
- Только то, что есть в коде. Если не уверен — пометь «не уверен» и укажи файл.
- Тексты для пользователя приводи дословно, по-русски, как в коде.
- Не объединяй разные функции в одну строку, даже если они похожи.
- Не пропускай мелкие и служебные функции.
