# Сверка: решения 28.10 и Rust-репозиторий `yzolotarev/cognitive-popups`

Дата: 28.10.2026. Источник: клон `yzolotarev/cognitive-popups` (коммит `8f12016` от 27.10).
- `docs/spec/cognitive_exoskeleton_v0_2_full_spec.md`;
- `docs/decisions/open-decisions.md` (OD-01…OD-13);
- `docs/requirements/legacy-inventory.md`.

## Что это за репозиторий

- Новая попытка на Rust. Стадия «P2 in progress».
- Есть спецификация v0.2, реестр требований с тестом трассируемости, журнал событий (`crates/journal`, ~400 строк), доменная модель (~430 строк), пробы Slint и Tauri.
- Приложения нет, GUI не выбран.
- Основа разработки — v1 на Python (B2, подтверждено владельцем 28.10). Ценность Rust-репозитория — в документах, а не в коде.

## Инварианты Rust-спеки: переносим как есть

INV-01…INV-09 согласуются со всеми решениями 28.10 и становятся критериями приёмки систем (B10):

| INV | Суть | Где у нас |
|---|---|---|
| INV-01 | Исходный текст, мысль пользователя и текст ИИ не смешиваются | Разметка `->user:` / `->ai…` (Q-30), B18 (значок «ИИ») |
| INV-02 | «Завершил» / «освоил» не создают Good | A7, B27 |
| INV-03 | Интерпретация LLM ссылается на реальные события | Q-30, B21 |
| INV-04 | Повтор события не создаёт лишний review | F-34 |
| INV-05 | Помощь, «не знаю», заблокированный шаг, ошибка, успех — разные состояния | F-97 + `self_graded` (B33) |
| INV-06 | «Отложено» ≠ «забыл», не портит FSRS | F-35, Q-48 (пауза цели) |
| INV-07 | Комплексный ответ не обновляет слепо все части | B32: ошибка на объединённой единице → Again только ей |
| INV-08 | Прерванный Alt+I восстанавливается без фальшивого завершения | A6, F-27 |
| INV-09 | Без consent нет фоновой записи и инициативных окон | F-56, F-59, B16 |

## Итог

1. Rust-спека и решения 28.10 в основном **совпадают**. Расхождения: OD-01 (подтверждение единиц), OD-02 (слияние), OD-05 («не помню»), OD-10 (приоритет платформ).
2. По OD-01, OD-02 и OD-10 действуют решения владельца 28.10. По OD-05 принято уточнение (B34).
3. Из Rust-репозитория берём: инварианты INV-01…INV-09 как критерии приёмки, протокол MRT из OD-06 как первый эксперимент, политику данных из OD-11.
4. Код Rust-репозитория не используется (B2).
