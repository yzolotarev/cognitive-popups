# GUI spike: Tauri vs Slint

Одноразовые пробы, **не** часть продукта и не собираются в CI. Цель — сравнить
стеки на одном сценарии до выбора OD-09: маленькое полупрозрачное окно без рамки,
кириллица, автозакрытие, замеры запуска/памяти/фокуса.

## Как запускать

```bash
cd spikes/slint-probe && cargo build --release
cd spikes/tauri-probe && cargo build --release

cd spikes
./probe.sh slint-probe 2 ./slint-probe/target/release/slint-probe
WEBKIT_DISABLE_DMABUF_RENDERER=1 \
  ./probe.sh tauri-probe wait ./tauri-probe/target/release/tauri-probe
```

`probe.sh` фиксирует активное окно до/после показа, RSS через 1 с, геометрию окна
и снимает только область самого окна в `/tmp/opencode/<label>-window.png`.

## Замеры (Arch, Hyprland 0.56.2, Wayland, 27.10.2026)

| Метрика | Slint 1.18 | Tauri 2 |
|---|---|---|
| Холодная сборка release | 6 мин 06 с | ≈ 4 мин (134 с + 103 с + 107 с, кэш реестра тёплый) |
| Размер бинарника | 15.2 МБ | 5.7 МБ + системный WebKitGTK |
| Время до показа | `show()` 43 мс | page load 0.79–0.90 с |
| RSS через 1 с | 120–128 МБ | 160–166 МБ |
| Прозрачность | работает сразу | работает только с `WEBKIT_DISABLE_DMABUF_RENDERER=1`; без него — `Error 71 (Protocol error)` и падение через ~1 с |
| Рамка/скругления | скругления рисуются | окно прямоугольное, скругления только внутри HTML |
| Кириллица, `≠`, перенос | корректно | корректно |
| Фокус | **крадёт** | **крадёт** (`focus: false` в конфиге не сработал на Hyprland) |

## Ограничение, общее для обоих

Обычный toplevel на Hyprland активируется при появлении. Проверить правило
композитора в этой сессии не удалось: Hyprland 0.56 использует не-legacy парсер,
`hyprctl keyword windowrule` возвращает «Use eval», а временная правка конфига
пользователя без разрешения недопустима. Поэтому «показ без кражи фокуса» пока
**не подтверждён**; кандидаты — правило `noinitialfocus` в конфиге Hyprland,
layer-shell-оверлей или отдельный путь для Windows (`SW_SHOWNOACTIVATE`).

Это не мелочь: PR-06 требует, чтобы пассивный показ не крал фокус. Пока механизм
не подтверждён, нельзя обещать выполнение PR-06 на Hyprland.

## Что уже видно

- Tauri на этом окружении требует обходного env-переменной для WebKitGTK; считать
  поведение одинаковым на других GPU/дистрибутивах нельзя.
- Tauri даёт лучший внешний вид «из коробки» (HTML/CSS), но добавляет WebKitGTK и
  связанные ограничения.
- Slint ближе к нативному рендерингу, показывает окно за 43 мс и переживает
  Wayland без обходов, но даёт больший бинарник и меньше готовых компонентов.
- Ни один стек не решает задачу «оверлей без фокуса» сам по себе.

## Рекомендация для OD-09 (не решение)

Продолжать на **Slint** для контекстных окон и отдельно проверить механизм
«без фокуса» на уровне окружения. Если кража фокуса окажется неустранимой без
layer-shell, вернуться к сравнению: у Tauri путь к gtk-layer-shell ближе, потому
что Linux-окно — GTK.

Окончательный выбор делает автор после прочтения замеров.
