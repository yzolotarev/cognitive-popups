# P0: проба стека Rust + GTK 4 + gtk4-layer-shell

Решает судьбу Rust (B35, `docs/v2/ROADMAP.md`, P0). Нужен Hyprland.

## Установка (Arch)

```sh
sudo pacman -S --needed gtk4 gtk4-layer-shell typst
```

`typst` нужен для критерия 4 (формула). Без него окно покажет формулу текстом, и это запишется как риск.

## Запуск

```sh
cd spikes/gtk4-probe
./run.sh
```

Около двух минут:
- **замер задержки:** 20 показов заранее созданного окна, без участия;
- **ручные шаги:** 6 коротких проверок. На каждую — Enter и одно слово, `ok` или `нет`.

В конце скрипт печатает блок «ОТЧЁТ» — его нужно прислать целиком.

## Что проверяется

| № | Критерий | Строка в отчёте |
|---|---|---|
| 1 | Окно у курсора без захвата клавиатуры; клик включает ввод | `manual: 1a/1b`, `keyboard=on_demand` |
| 2 | От сигнала до кадра < 100 мс (baseline OD-13) | `latency_ms median/p95` |
| 3 | Русский ввод и вставка | `input=…`, `manual: 3` |
| 4 | Формула `P(A∣B) = P(A∩B) / P(B)` локально | `formula=typst` или `risk=no_typst` |
| 5 | Esc закрывает; второй вызов поднимает то же окно | `closed_by=escape`, `second_show=raised_existing` |
| 6 | Окно по горячей клавише сразу получает клавиатуру (INV-13): какой режим работает на Hyprland | `manual: 6a/6b`, `keyboard_focus=gained` |

## Уже проверено в контейнере (headless sway)

- layer-shell поддерживается, окно рисуется;
- второй вызов не создаёт второе окно;
- задержка при программной отрисовке: median 2,3 мс, p95 4,5 мс.

Клик и клавиатуру headless sway не передаёт, поэтому критерии 1, 3, 5 и 6 проверяются только на Hyprland.
