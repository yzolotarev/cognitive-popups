§ 1. Коробки с жетонами
Здесь рассматриваются два ящика на игровом столе. Цвет ящика не связан с числом жетонов внутри.

1. Терминология
Определение. Запасом коробки называется число лежащих в ней жетонов. Пустая коробка имеет запас ноль.
Назовём парным запасом сумму запасов двух выбранных коробок.

2. Перекладывание жетона
Метод подсчёта после переноса: вычтем один из запаса первой коробки и прибавим один к запасу второй. Процедура допустима, если первая коробка не пуста.

Теорема 1. Перенос одного жетона между двумя коробками сохраняет их парный запас.
Доказательство. Пусть до переноса запасы равны a и b. После переноса их сумма равна (a - 1) + (b + 1) = a + b. Следовательно, сумма не изменилась.

Теорема 2. При запасах a и b разность запасов после переноса из первой коробки во вторую равна a - b - 2.
Доказательство. Вычитая новый запас второй коробки из нового запаса первой, получаем (a - 1) - (b + 1) = a - b - 2.

3. Сравнение запасов
Теорема 3. Если в первой коробке на два жетона больше, чем во второй, один перенос из первой во вторую уравнивает запасы.
Теорема 4. Если запасы одинаковы и положительны, перенос из первой коробки во вторую делает запас второй на два больше.
Доказательство. Для исходных запасов a и a новые значения равны a - 1 и a + 1. Их разность равна двум.

4. Задача о выдаче игровых жетонов
Перенос используется при раздаче жетонов двум участникам. Метод позволяет изменить доли игроков без добавления жетонов в игру. Для проверки общего количества применяется теорема 1.

Пример 1. В первой коробке пять жетонов, во второй один. После переноса остаются четыре и два; общий запас по-прежнему равен шести.
Пример 2. В двух коробках лежат три и три жетона. Один перенос даёт запасы два и четыре.

Замечание 1. Цветные наклейки нужны только для различения коробок на рисунке.

Упражнения
Решите задания для двух коробок с неотрицательными целыми запасами.
1. Формулу a + b проверьте для запасов четыре и семь до и после одного переноса.
2. Найдите начальные запасы, при которых один перенос уравнивает количество жетонов.
